# Tiny Stack VM

Exact interpreter for make.fun's tiny stack ISA v1, built for the [tiny-stack-vm-01](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty: 32-bit wrapping math, all ten traps, step/output limits, one dependency-free file.

Node 22:

    node main.ts [inputRoot] [outputRoot]

Answers all instances under input root (defaults: /input, /output).
